## 2. 独立预期

配置：`examples/config/synthetic_stream_framing_slice.pae.json`。

- `fixed_message` 的偏移 0 Matcher 为固定字节 `AA`；
- `fixed_payload` 位于偏移 1，宽度 2，使用 big endian，类型为 `UINT64`；
- 因此手写输入 `AA 00 07` 的逻辑值为 7；
- 类型化 Encode 输入 7 的独立预期也为 `AA 00 07`。

程序同时核对公开 metadata 的 Schema、Protocol、Pipeline、Message、Field、动作可用性及精确输出容量，
不从 Codec 的实际输出生成预期。
