# 中文协议配置教程

先阅读 [01 配置结构与二进制](01-配置结构与二进制.md)，再阅读 [02 文本与流式](02-文本与流式.md)。本目录的两份 `.pae.json` 是完整配置，可以在 Lab 中通过“浏览”加载；不是不能运行的节选。所有数据为公开合成数据。

本目录随体验包根目录交付。SDK 用户也使用这些配置，不需要复制整个开发仓库。原有 `synthetic_*` 配置保留测试用途；特别是 `synthetic_ui_max` 不作为入门起点。

## 按目的阅读

| 你要做什么 | 阅读入口 |
| --- | --- |
| 理解字节如何对应字段 | [01 配置结构与二进制](01-配置结构与二进制.md) |
| 理解文本与流式的区别 | [02 文本与流式](02-文本与流式.md) |
| 编译并运行最小C++验证程序 | [03 构建运行教学程序](03-构建运行教学程序.md) |
| 查常用参数与引用规则 | [04 常用配置字段速查](04-常用配置字段速查.md) |
| 从协议表写配置并定位错误 | [05 从协议表到SDK练习](05-从协议表到SDK练习.md) |

第一次不用读完整Schema或工程历史。先完成01，再按03运行，最后按05自己练习；04作为随手查阅，不要求背诵。

JSON 不允许 `//` 或 `/* */` 注释。中文说明使用 Schema 已允许的 `display_name`、`description`，不要自行添加 `_comment`，也不要在 `wire` 等未允许说明属性的对象中塞入 `description`。字段键、枚举值和引用 ID 不翻译。中文元数据不意味着支持中文报文；文本例子的线上编码仍是 ASCII。

`*.pae.json` 是配置实例；`pae.schema.json` 是校验实例结构的规则文件，不是另一份设备配置。结构校验之外，编译器还检查引用、布局、方向和资源限制。
