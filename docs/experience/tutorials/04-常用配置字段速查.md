# 04 常用配置字段速查

本页针对教学配置的Binary 0.9完整记录和ASCII 0.10完整记录，不是全版本字段字典。“必填”限定在表中对象和本例分支；不要推广到其他wire编码、计算字段或变长布局。没有列出的属性及条件约束请查随包 `schema/pae.schema.json`。

## 公共结构

| 位置与属性 | 类型与要求 | 用法与常见误解 |
| --- | --- | --- |
| 根 schema_version | 必填字符串 | 如"0.9"或"0.10"；不是浮点数，不默认选择最新版 |
| 根 protocol_id | 必填稳定ID字符串 | 机器身份；不等于文件名或显示名称 |
| 根 protocol_version | 必填字符串 | 作者协议版本，不等于Schema版本 |
| 根 display_name / source_ref | 必填字符串 | 人类名称与来源标识；来源不是自动加载路径 |
| 根 description | 可选字符串，最多1024字符 | 不填时没有额外说明，不提供执行默认规则 |
| 根 resource_profile | 必填desktop或constrained | 资源档位，不是传输方式 |
| 根 framing_profiles / pipelines / messages | 必填非空数组 | 分别定义边界、管线、消息；不能拿名称代替ID引用 |
| 上述数组成员 id / display_name / description / source_ref | 本例必填字符串 | id用于引用；说明元数据不能替代执行属性 |
| framing profile input_kind | 本例必填complete_record | 宿主提供完整记录；切流需使用不同规则分支 |
| pipeline direction_id | 必填ID字符串 | 与所引用消息方向一致；不创建通信线程 |
| pipeline input_framing_profile_id | 必填ID引用 | 必须对应一个framing profile的id |
| pipeline message_ids | 必填非空ID数组 | 允许该管线处理的消息集合 |
| message direction_id | 必填ID字符串 | 不是Lab的Decode/Encode动作选择 |
| message fields | 必填数组 | Binary本例含一个字段；ASCII纯字面量例子可为空 |

## Binary固定整数分支

| 位置与属性 | 类型与要求 | 单位与意义 |
| --- | --- | --- |
| message frame_length_bytes | 必填正整数 | 完整记录的总字节数，包含标识 |
| message matcher.all | 必填条件数组 | 本例fixed_bytes条件要求指定偏移的字节相符 |
| fixed_bytes byte_offset / bytes | 必填非负整数 / 十六进制字符串 | 偏移从0开始；bytes不是ASCII文字AA |
| field id / display_name / description / source_ref | 本例必填字符串 | 字段身份与说明 |
| field value_type | 本例必填UINT64 | 逻辑值类型，不决定线上字节宽度 |
| field wire.codec | 本例必填unsigned_integer | 其他编码有各自属性组合 |
| wire byte_offset / byte_width | 必填整数 | 起点为零基偏移；宽度单位字节，本整数编码1到8 |
| wire byte_order | 宽度至少2字节时必填big_endian或little_endian | 本例2字节必须填；1字节时可省略，不依赖本机CPU字节序 |
| field encode.source | 本例必填input | 宿主提供类型化值；不是从description取值 |

本例没有省略默认值来简写配置。长度、偏移、类型范围和固定字节仍要通过编译器的交叉检查，JSON类型合法不等于布局可执行。

## ASCII字面量分支

| 位置与属性 | 本例要求 | 意义 |
| --- | --- | --- |
| message layout.kind / encoding | text / ascii | 文本布局及线上编码 |
| layout.decode / layout.encode | 本例显式提供两者 | 是两个独立动作模板；不要从一个模板推算另一个 |
| action.segments | 按顺序排列的片段数组 | 本例仅一个literal；动态字段见原text_slice样例 |
| literal.kind / text | literal / 字符串 | 固定字节内容，JSON转义\r\n表示CRLF |

仅有某一动作的ASCII配置应使用对应规则，不能依据此表推断decode/encode永远都必填。JSON没有注释语法，未知属性通常被拒绝；不要添加未定义的备注键。
