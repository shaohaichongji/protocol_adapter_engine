# 03 构建运行教学程序

目标是在自己的C++程序中完成配置编译、Decode和Encode，再观察两个配置错误。程序只使用公开SDK，不依赖Qt，不联网，也不启动Lab。

## 准备环境

以下命令适用于完整体验包、Windows x64、PowerShell。需要CMake、Visual Studio 18 2026及MSVC v142 14.29.30133工具集，最终以同批包来源与验证记录核对；单独能启动Lab不代表已安装C++编译环境。先执行 `cmake --version` 确认命令可用。工具集缺失时按包的SDK接入说明准备环境，不要随意混换DLL或其他编译器。

先在PowerShell中进入**解压后的体验包根目录**，该目录同时有 `README.md`、`tutorials`、`sdk` 和 `lab`。以下路径都相对于这里；不是在仓库根或tutorials内部执行。

```powershell
$bundle = (Get-Location).Path
$sdk = (Resolve-Path './sdk/pae-sdk-static-release').Path
$build = Join-Path (Split-Path $bundle -Parent) 'pae-tutorial-build-release'
if (Test-Path -LiteralPath $build) { throw 'Choose a fresh BuildRoot' }
cmake -S './tutorials' -B "$build" -G 'Visual Studio 18 2026' -A x64 -T 'v142,version=14.29.30133' "-DCMAKE_PREFIX_PATH=$sdk"
```

预期以 `Configuring done`、`Generating done` 结束。此步只生成构建系统，不会运行协议。首次应使用不存在的新build目录；更换SDK时换一个新目录，避免旧 `PAE_DIR` 缓存选中另一包。

确认上一条命令成功后，逐条运行：

```powershell
cmake --build "$build" --config Release
ctest --test-dir "$build" -C Release --output-on-failure
```

预期编译得到 `Release/config_tutorial.exe`，预期CTest显示4/4通过。构建目录放在体验包旁边，避免生成物混入包的哈希清单。这些是后续 Static Release 的验证步骤；本轮文档准备未运行教学程序，不代表任何组合已通过。

## 单独运行与查看输出

```powershell
& "$build/Release/config_tutorial.exe" './tutorials/01-最小二进制.pae.json' binary
& "$build/Release/config_tutorial.exe" './tutorials/02-最小文本.pae.json' ascii
& "$build/Release/config_tutorial.exe" './tutorials/01-最小二进制.pae.json' missing-property
& "$build/Release/config_tutorial.exe" './tutorials/01-最小二进制.pae.json' unknown-reference
```

每条成功时输出 `TUTORIAL PASS`，退出码0。后两条先打印预期错误码、JSON pointer和detail，再输出PASS：这里的PASS表示**正确拒绝坏配置**，不表示坏配置编译成功。注入只修改内存副本，不损坏文件。

程序是固定向量验证器，不支持任意报文输入参数。Binary模式固定使用 `AA 01 02` 与value=258，ASCII模式固定使用PING/PONG；它不是通用命令行协议工具。错误命令或读文件失败返回2，其他非零退出码表示对应断言未满足，请同时保留输出。

## 对照源码阅读

依次在 [verify.cpp](verify.cpp) 中找到：读取JSON → `CompileProtocolJson` → `TakeCompiled` → `CreateCompleteRecordCodec` → `Decode` → 读取UInt64 → `Encode` → 对比预期字节。错误模式提前在编译结果处返回，不创建Codec。

配置中的ID与API中的index不同：本例只有一个管线、一个消息和一个字段，明确使用索引0；不要把这个约定复制到多消息宿主。通用宿主应通过metadata定位索引并检查查询结果。
