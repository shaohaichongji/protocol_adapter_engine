# 开发者指南

这里是面向人类阅读的顺序入口。主线只回答“项目是什么、怎样第一次运行、怎样接入、怎样配置、怎样读代码、怎样排错”，精确契约和历史验证另放在 [工程依据](../engineering/README.md)。

## 主线阅读顺序

| 顺序 | 文档 | 适合谁 | 读完后的下一步 |
| ---: | --- | --- | --- |
| 01 | [项目定位与能力边界](01-项目定位与能力边界.md) | 所有人 | 选择 Lab、SDK 或维护路线 |
| 02 | [首次运行与 Lab 体验](02-首次运行与Lab体验.md) | 新用户、评估者 | 启动本机 Lab，观察合成配置 |

## 三种工作对象

- **本机已归集产品**：`deliverables/`，适合直接体验；它被 Git 忽略，不随 clone 自动获得。
- **SDK 候选**：先读 03，再读具体包内 `PAE-SDK-README.md`；包内说明优先于通用指南。
- **开发树**：先读 05/06，再按根 `CMakePresets.json` 和当前源码工作。

## 共同边界

当前 SDK/Lab 是限定 Windows x64 本地候选，不是正式发布；Debug/Release、Static/Shared 必须配对。PAE 不拥有通信、线程、设备生命周期或 UI。Linux、稳定 ABI、真实协议、硬件、现场与生产能力必须按独立证据判断。
